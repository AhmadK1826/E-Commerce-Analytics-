# E-Commerce Analytics Dashboard | Power BI

An interactive Power BI dashboard developed to analyze e-commerce website traffic, orders, conversion performance, and marketing channel performance.

## 📊 Dashboard Pages

### 1. Website Traffic & Order Trends
Analyzes website sessions and order volume over time and tracks month-over-month growth.

### 2. Session-to-Order Conversion Analysis
Analyzes session-to-order conversion trends over time and compares conversion performance across marketing channels.

### 3. Marketing Channel Performance
Evaluates marketing channels using orders, total sales, gross profit, and average order value.

## 🛠️ Tools & Skills

- Power BI
- Power Query
- DAX
- Data Modeling
- Time Intelligence
- Data Visualization
- Business Intelligence

## 🗂️ Data Model

The project uses a Fact Constellation (Galaxy) model with multiple fact tables and shared dimensions to support website activity, sales, and refund analysis.
